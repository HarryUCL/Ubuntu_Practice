阶段性三：检查SSH
检查SSH服务：
hamster@hamster-virtual-machine:~/桌面$ dpkg -l | grep openssh
ii  openssh-client                             1:8.9p1-3ubuntu0.10                               amd64        secure shell (SSH) client, for secure access to remote machines
由此可知，Ubuntu虚拟机只安装了OPENSSH Client，没有OPENSSH Server。

阶段四：安装SSH服务端
hamster@hamster-virtual-machine:~/桌面$ sudo apt update
hamster@hamster-virtual-machine:~/桌面$ sudo apt install openssh-server -y

hamster@hamster-virtual-machine用户是普通用户，但sudo让系统以管理员权限执行指令。
apt是软件包管理器。
update 更新软件包目录。
-y 自动确认如 Do you want to continue? [Y/n]
思路是1.更新目录。2.解析依赖后下载和安装文件。

阶段四 核实无误
启动SSH服务，并设置开机自启动
hamster@hamster-virtual-machine:~/桌面$ sudo systemctl enable --now ssh
检查服务状态
hamster@hamster-virtual-machine:~/桌面$ sudo systemctl status ssh
检查端口监听
hamster@hamster-virtual-machine:~/桌面$ sudo ss -tlnp | grep :22
ss: Socket Statistics. 查看网络连接信息。输出非常多，需要参数筛选。
-t: 只显示TCP套接字。因为SSH默认使用TCP。
-l: 套接字，表示监听。
-n: 表示数字形式的地址和端口。如0.0.0.0:22
-p: 进程。
 | ：管道符号。首先执行ss -tlnp，获取输出，最后传给下一个命令。
grep: 22 :筛选包含22的文本行。
最终取得: 22端口相关信息。

0.0.0.0是IPv4通配的监听地址，表示所有IPv4接口
ps aux | grep python
aux:
a: 与终端关联的进程。
u: 面向用户的进程。
x: 包含没有关联终端的进程。

kill 1024
结束PID为1024的进程
